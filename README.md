# AI-Powered E-Commerce DevOps Platform

## Project Overview
A demonstration of DevOps practices for a containerized
E-Commerce frontend.

## Technologies
- Ubuntu Linux
- Git and GitHub
- Docker and Docker Compose
- Jenkins
- Terraform
- Ansible
- Kubernetes
- Prometheus and Grafana
- Trivy

## Application
A demo storefront with product listings and a client-side cart.

## Run the Application
docker compose -f docker/docker-compose.yml up -d --build

Open http://localhost:8082

## Project Objectives
- Containerization
- CI/CD automation
- Security scanning
- Infrastructure automation
- Kubernetes deployment
- Monitoring and logging
- AI-assisted incident analysis
